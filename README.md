# BOM 🏖️

BOM is a vacation rental platform focused exclusively on Bombinhas, Santa Catarina, Brazil.

## 🎯 Project Goal

The goal of BOM is to connect property owners with people looking for short-term accommodations in Bombinhas through a simple and user-friendly platform.

Property owners will be able to publish and manage their properties, while guests will be able to search for available accommodations based on check-in and check-out dates.

## 🚀 Main Features

### Property Owners

- Create an account.
- List one or multiple properties.
- Add property information and photos.
- Set the price per night.
- Manage availability through a calendar.
- Receive booking requests.

### Guests

- Create an account.
- Search for available properties.
- Select check-in and check-out dates.
- Specify the number of guests.
- View property information and photos.
- Send booking requests.
